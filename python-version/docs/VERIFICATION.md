## 已由测试锁定的高风险行为

- PDF/DOCX/TXT/GB18030 与粘贴文本导入；扫描版 PDF 和旧 `.doc` 明确拒绝。
- 清洗 CRLF、制表符、零宽字符、页码与分隔线，并对常见乱码模式给出告警。
- 原 Java 项目四份回归简历的字段、项目分块、技术栈、低置信度与隐私边界。
- 手机号多种写法、座机、邮箱、身份证、URL、地址与日志脱敏；事实标签和人工修正元数据同样脱敏。
- 哈希向量确定性、简历间隔离、知识/简历来源区分、幂等重建与删除。
- 检索 topK、最低融合分与上下文长度可配置；低于阈值不强行召回，空查询选题不受阈值误伤。
- 模型 JSON 常见畸形修复，以及数组/对象/顶层分数、中文维度、10/100 分制归一。
- 参考回答不得引入无依据量化指标；用户回答的无依据指标会产生告警。
- 报告雷达仅统计模型实际返回的维度，缺失维度保持 `sample=0`，不会以零分稀释均值。
- 重答、换题、追问预算、题量上限、完整面试阶段、错误码和报告。
- 最后一题回答后仍允许重答；再次请求出题会按 Java 契约自动结束；生成报告会自动结束未结束会话。
- 多项目按未覆盖主题依次选题；会话持久化当前聚焦项目和规范化覆盖主题，不会把 citation 前缀重复计为新主题。
- 并发重复提交只能成功一次，避免回答数与报告统计污染。
- 未知路由、错误 HTTP 方法、非法 JSON、字段类型错误与超限上传均使用统一错误结构和正确状态码。
- JSON 原子替换、损坏文件隔离、更新/删除落盘、会话/问题/回答/评分/报告聚合重开、跨进程恢复与启动期索引重建。
- OpenAI 兼容协议的 JSON 模式协商、思考链抑制、模型名诊断与地址发现。
